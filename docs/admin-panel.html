Admin Panel

Web-based management interface for ai-server-agent — topics, scheduler, and system settings

Architecture

The admin panel runs as a background Node.js process alongside the heartbeat loop. Both share data/state.json and data/schedules.json via atomic writes. The panel is opt-in: it only starts when ADMIN_TOKEN is set in config.

Schedule Execution Engine

bin/schedule-run.sh is extracted from heartbeat.sh into a standalone script. It is the single execution path for all scheduled tasks — called by the heartbeat loop, the panel API, and Telegram commands.

Schedules Tab

Friendly time picker for scheduling — select days and time visually, rather than typing raw cron. The UI converts to/from cron expressions internally. "Run Now" uses a play icon for quick recognition.

Heartbeat sync: Scheduled tasks only execute during heartbeat polls. The effective minimum interval is the heartbeat interval (configurable in Settings). If heartbeat runs every 30 minutes, a schedule set to "every 5 minutes" will only fire once per heartbeat cycle. The scheduler UI displays the effective next run time accounting for heartbeat interval.

Topics

Schedules
GET/api/schedulesRead schedules.json array
POST/api/schedulesAdd new schedule entry
